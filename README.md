# Roost

Fusion Nest's Mac utility for converting and optimising files: a corner dropzone for images,
SVG → AI, Word → PDF, PowerPoint flattening, and Perch, a folder picker beside Save and Open
dialogs.

This repository only hosts releases. **Download:**
[Roost.dmg](https://github.com/fusionnest-ca/roost-releases/releases/latest/download/Roost.dmg) —
open it and drag Roost into Applications. Roost keeps itself up to date after that.

Managed Macs: push [Roost.pkg](https://github.com/fusionnest-ca/roost-releases/releases/latest/download/Roost.pkg) from your MDM.

Requires macOS 13 or later. Illustrator, Word and PowerPoint are needed for their conversions.
